# Session 7 — guide consolidé à deux navigateurs

Version intermédiaire 7d du 29 octobre 2026. Environ 30 minutes hors durée d'envoi des gros assets. Ce guide couvre le produit livré ; il **ne clôt pas** les essais CPU, gros volumes, convertisseur permanent et comparaison finale encore ouverts dans la [fiche 7d](session-7-7d-revue.md).

Utiliser un workspace de test et deux comptes distincts : A propriétaire avec facteur fort récent, B invité dans un autre navigateur ou une fenêtre privée. Ne pas exécuter les fichiers téléchargés pour ce test. Préparer une petite image JPEG/PNG, un script texte inoffensif, une archive sans contenu dangereux et un fichier d'au moins 81 Mio. Vérifier que les services API, web, collaboration, worker, stockage et files sont démarrés ; aucun contournement d'alerte TLS.

1. **Droits (3 min).** Avec A, partager une page et une base de tâches avec B en lecture. B voit uniquement les éléments partagés. Il peut ouvrir une ligne ; les cellules et le contenu restent non modifiables et la raison est affichée. Un autre parent caché ne doit pas apparaître.
2. **Image dans une page (4 min).** Avec A, ajouter un bloc image et envoyer le JPEG/PNG. Après validation, utiliser le bouton actuel « Vérifier et joindre le fichier ». Constater l'état de préparation puis l'aperçu ; B le voit après synchronisation. L'original se télécharge, seul le dérivé est affiché. L'attachement automatique, le glisser-déposer et le collage sont des finitions pré-pilote, pas disponibles par cette livraison.
3. **Asset dans une tâche (4 min).** A ajoute une propriété fichiers si nécessaire. Passer B en édition. B joint un asset à une cellule puis confirme la valeur ; A le voit. B peut modifier sa tâche mais ne peut changer le schéma de la base. Deux éditions concurrentes de la même cellule affichent le conflit avec saisie conservée, sans écraser silencieusement l'autre.
4. **Interruption/reprise (5 min, plus transfert).** B commence l'envoi du gros fichier, coupe temporairement le réseau après une partie, puis rétablit le réseau et recharge. « Reprendre un envoi » propose les intentions de cet auteur dans cette page. Choisir d'abord un autre fichier : refus ; resélectionner ensuite le bon : reprise et validation. Ne pas interpréter la signature d'une partie ou le transfert fini comme une référence déjà enregistrée.
5. **Téléchargement à risque (3 min).** Joindre le script inoffensif et l'archive. Vérifier l'avertissement avant téléchargement ; annuler une fois, confirmer ensuite. Ne pas les exécuter. Un SVG ou HTML déguisé avec une extension image ne doit jamais se rendre comme un original inline. Le message n'affirme pas que le fichier est exempt de malware.
6. **Révocation (4 min).** B ouvre l'aperçu et une ligne. A réduit puis retire son partage. B perd l'accès concerné ; une ancienne URL de lecture ne fonctionne plus. Une autre page sans changement de droit reste ouverte. Le test automatique de flux lent vérifie la coupure effective sous cinq secondes ; un téléchargement terminé ne peut pas être effacé à distance.
7. **Cache et onglet retardataire (4 min).** Réaccorder B, ouvrir un aperçu, mettre son navigateur hors ligne. Retirer le droit depuis A, rétablir B : l'ancien aperçu ne doit pas réapparaître après retour/rechargement. Répéter avec interdiction du cache du workspace puis déconnexion depuis un second onglet du même navigateur. La suite `pnpm test:files:ui` ajoute le gel réel CDP et la réponse réseau retardée, difficiles à reproduire exactement à la main.
8. **Récupération technique isolée (3 min).** Exécuter `pnpm test:files:gateway-recovery` et lire son résumé réussi. Le script coupe et redémarre uniquement son PostgreSQL dédié ; ne pas reproduire ces commandes sur le développement ou un studio réel. Les lectures sont fermées pendant la panne, puis de nouveau possibles après contrôle ; les sessions révoquées restent refusées.

Noter navigateur, fichier/type/taille, étape et résultat inattendu. Ne joindre ni URL signée, cookie, secret, contenu personnel ni export de console brut au compte rendu. Les essais matériels/mémoire et de débit restent ceux des bancs avec leur protocole ; ce parcours manuel ne constitue pas un test de capacité.
