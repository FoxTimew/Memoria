## Routes et quotas réellement appliqués

Préfixe Nest : `/api/internal/workspaces/:workspaceId`. U/P/L/M sont cumulés entre sessions et workspaces, par IP réelle et compte, en plus du quota global. Toutes ces routes restent derrière le guard global, session injectée, origine contrôlée pour les mutations, corps stricts et admission bornée. `assertFileRouteMatrix` compare désormais les méthodes HTTP présentes à l'inventaire fermé ci-dessous ; un ajout non recensé fait échouer les tests.

## Scénarios d'attaque et limites de preuve

| Frontière attaquée                                             | Test réel ou absence de test                                                                                                                                                 | Ce que la preuve ne garantit pas                                                                                                    |
| -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Voler une intention, changer workspace/page/auteur             | HTTP transferts, IDs échangés et session étrangère                                                                                                                           | Un compte légitime compromis reste un principal autorisé                                                                            |
| Contourner MFA par session de récupération                     | Toutes familles HTTP ; politiques et ticket ancien testés                                                                                                                    | Pas de nouvelle revue de toutes les routes auth, inchangées depuis session 4                                                        |
| Insérer un fichier inaccessible dans un lot Yjs ou une cellule | WSS/HMAC, lots par auteur, CAS et conservation des liens masqués                                                                                                             | Futurs imports/API publique à attaquer avant ouverture, R12 permanent                                                               |
| Retirer le droit pendant journalisation ou attache             | Courses SQL/S3 réelles, rollback, retrait immédiat                                                                                                                           | Capacité à la borne de fan-out à mesurer en charge mixte                                                                            |
| Collecter un objet encore référencé ou publier un vieux job    | GC/attache concurrente, epoch de job, réponse ambiguë et crash worker                                                                                                        | Crash/restauration complète RustFS à volume pilote reste pré-pilote                                                                 |
| Rejouer une signature pour remplacer des octets déjà validés   | POST rejoué, copie finale immuable, SHA complet vérifié                                                                                                                      | Pas de plafond réseau strict par compte sur un URL volé/rejoué                                                                      |
| Déguiser SVG/HTML/exécutable en image                          | Décodeur réel, téléchargement forcé, aperçu réencodé, avertissement UI                                                                                                       | Ni détection complète des polyglottes ni garantie antivirus                                                                         |
| Bombe de pixels, raster corrompu, métadonnées privées          | Bornes de dimensions, image malformée, EXIF/GPS absent du dérivé                                                                                                             | Formats non pris en charge téléchargés ; nouvelles bibliothèques à requalifier                                                      |
| Forger/rejouer ticket, Range abusif, réduire l'accès           | HTTP gateway et flux lent coupé, contrôle périodique sans notification                                                                                                       | Octets déjà reçus, captures et téléchargements externes non récupérables                                                            |
| Perdre LISTEN puis redémarrer PostgreSQL                       | Nouveau `apps/files/src/recovery.e2e.ts`, panne réelle isolée                                                                                                                | Reprise de toute la pile et du leadership collaboratif non couverte                                                                 |
| Publier une autorisation traversant une panne                  | Autorisation retenue puis LISTEN recréé ; refus 503 par époque                                                                                                               | Test déterministe d'une course, pas une preuve exhaustive de tous les ordonnancements                                               |
| Échapper aux quotas avec IP forgée                             | HTTP API/gateway, sessions agrégées, IP du proxy seulement                                                                                                                   | Protection amont globale reste nécessaire, pas qualifiée par ces tests                                                              |
| Fuite de capacité dans une exception                           | Nouveau canari SDK : vrai HTTP, retry worker, audit/outbox                                                                                                                   | Injection ciblée ; ne couvre pas tout middleware/provider/opérateur externe                                                         |
| Fuite au proxy après erreur réelle                             | HTTPS navigateur, backend fermé : 502 ; journal Caddy sans ticket/nom                                                                                                        | Logs S3 et collecteurs externes à auditer séparément avant clôture                                                                  |
| Réanimer aperçu/cache après révocation, gel ou logout          | Interface finale Next/Nest/WSS, réponse retardée, cache interdit                                                                                                             | Un navigateur figé/hors ligne ne peut effacer avant réveil ; copies manuelles non contrôlables                                      |
| Saturation CPU et CONTROL_UNAVAILABLE                          | **Absence de test 7d exécuté à ce stade**                                                                                                                                    | Aucun délai de reconnexion ou absence de perte sous cette panne déclaré prouvé                                                      |
| Connexion abandonnée quand un éditeur reste seul sans saisir   | `pnpm test:collab:idle:browser` : vrai front visible 305 s, présence, aucun message d'erreur, contenu après rechargement                                                     | Un essai fonctionnel réussi ; ne couvre ni suspension du navigateur ni saturation CPU, voir [preuve](session-7-7d-front-inactif.md) |
| Compromettre le convertisseur permanent                        | `test-file-converter.mjs`, `exchange.test.ts`, `no-docker.test.ts` : sockets, écritures, quota tmpfs, crash, sorties falsifiées, dépendances du worker ; HTTP lecture rejoué | Kernel/codec zero-day, ACL de production et crash à chaque instruction non prouvés ; voir fiche convertisseur                       |
| Saturer les transferts et rafraîchissements légitimes          | **Mesures finales restantes**, trois séries exigées                                                                                                                          | Aucun résultat 50 comptes/gros fichiers déduit des tests fonctionnels                                                               |
